# Ethical Hacking (EH) — Unit III Examination Questions
**Course**: Ethical Hacking (MD***) | **VIT Pune**  
**Unit III**: System Hacking and Network Security

---

### Section A: 4-Mark Questions (Short Answer / Conceptual Clarity)
*Estimated time: 7-8 minutes per question*

#### Q3.1 [4 Marks]
(a) Define Password Spraying and Credential Stuffing. Explain why password spraying successfully bypasses traditional account lockout policies. **[2 Marks]**  
(b) Explain the cryptographic concept of Password Salting. Write the mathematical relationship and detail how salting completely neutralizes Rainbow Table attacks. **[2 Marks]**

#### Q3.2 [4 Marks]
(a) Differentiate between a computer **Virus** and a **Worm** based on host dependence, propagation autonomy, and infection velocity. **[2 Marks]**  
(b) Define a **Rootkit**. Explain how it achieves stealth by subverting operating system system calls, and explain why rootkits cannot be detected by standard user-mode monitoring tools like Task Manager. **[2 Marks]**

---

### Section B: 8-Mark Questions (Analytical / Methodological Depth)
*Estimated time: 15-18 minutes per question*

#### Q3.3 [8 Marks]
(a) Differentiate between **Vertical Privilege Escalation** and **Horizontal Privilege Escalation** with illustrative architectural diagrams. Provide two concrete exploitation examples for each (one on Linux and one on Web/Windows). **[4 Marks]**  
(b) Compare **John the Ripper** and **Hashcat** across architecture, hardware optimization, cracking modes, and enterprise usage. Provide the exact command syntax in John the Ripper to prepare Linux shadow files and crack them using a dictionary. **[4 Marks]**

#### Q3.4 [8 Marks]
(a) Analyze the inherent architectural vulnerability of the Address Resolution Protocol (ARP). Walk through the step-by-step execution of a **Man-in-the-Middle (MITM) attack via ARP Spoofing** between a victim and a gateway with a clear diagram. **[5 Marks]**  
(b) Specify three enterprise defensive controls against ARP spoofing, highlighting how **Dynamic ARP Inspection (DAI)** operates in conjunction with DHCP Snooping on managed switches. **[3 Marks]**

### Section C: 10-Mark Questions (Comprehensive / Scenario-Based)
*Estimated time: 22-25 minutes*

#### Q3.5 [10 Marks]
(a) **Network Security Controls & Firewall Evolution**:
1. Contrast the 4 generations of firewalls: **Packet Filtering (L3/4)**, **Stateful Inspection (L4/5)**, **Application Proxy (L7)**, and **Next-Generation Firewalls (NGFW)** in terms of operational layer, inspection depth, state tracking, and performance. **[4 Marks]**
2. Draw and explain an enterprise **Screened-Subnet DMZ Architecture**. Identify what services belong in the DMZ and state the fundamental firewall access rule governing DMZ-to-Internal LAN traffic. **[2 Marks]**  
(b) **Intrusion Detection vs Prevention Systems**:
1. Differentiate an **Intrusion Detection System (IDS)** from an **Intrusion Prevention System (IPS)** across deployment topology (in-line vs out-of-band), operational action, network latency impact, and failure modes. **[2 Marks]**
2. Compare **Signature-Based Detection** versus **Anomaly-Based Detection**. Detail why signature-based systems fail against Zero-Day exploits and why anomaly-based systems suffer from higher false positive rates. **[2 Marks]**
