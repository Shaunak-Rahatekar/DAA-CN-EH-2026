Unit I: Basic Complexity Analysis & Recurrences

Asymptotic bounds, Master Theorem, Variable substitutions, Decision trees, and Strassen

🔥 Guaranteed Question Topic 1.1

Non-Standard Recurrences (Square Root Substitution & Master Theorem)

💡 Asli Baat (1-Sec Recall): Agar recurrence me $\sqrt{n}$ dikhe, toh ghabrao mat! $n = 2^m$ daal kar usse normal Binary Search recurrence $S(m) = S(m/2) + 1$ bana lo. Answer hamesha $\mathbf{O(\log \log n)}$ aayega! Aur Master theorem me critical value $n^{\log_b a}$ nikaalo; jo term dominate kare wahi answer hai.
🎯 Standard Definition: Solving recurrences via domain variable transformation where $T(n) = T(\sqrt{n}) + c$ is converted to $S(m) = S(m/2) + c$ by defining $n = 2^m$, and standard divide-and-conquer recurrences $T(n) = a T(n/b) + f(n)$ via watershed comparison against $n^{\log_b a}$.
📐 Core Mathematical Formulas:
• $n = 2^m \implies m = \log_2 n \implies T(2^m) = T(2^{m/2}) + 1 \implies S(m) = S(m/2) + 1 \implies S(m) = O(\log m) \implies \mathbf{T(n) = O(\log \log n)}$
• Master Critical Exponent: $p = \log_b a$. If $f(n) = O(n^{p-\epsilon}) \implies \mathbf{T(n) = \Theta(n^{\log_b a})}$. (E.g. $T(n) = 3T(n/2) + n \implies n^{\log_2 3} \approx n^{1.585} \implies \mathbf{O(n^{\log_2 3})}$).
Exam Scenario / Disguise Underlying Paradigm Declared State / Substitution 4-Section Answer Rubric
Algorithms repeatedly taking square-root intervals (e.g. Jump Search / Sqrt Decomp) Variable Substitution $n = 2^m$, $S(m) = T(2^m)$ 1. State substitute $n=2^m$
2. Derive $S(m) = S(m/2) + 1$
3. Master Theorem on $S(m) \implies \Theta(\log m)$
4. Back-substitute $m = \log_2 n \implies \mathbf{O(\log \log n)}$
📚 CLRS 3rd Ed. & Actual Exam Practice Questions:
  • CLRS Ch. 4, Section 4.5 & Problem 4-1: Recurrences $T(n) = 3T(n/2) + n$ and $T(n) = 4T(n/2) + n^2$.
  • Actual Paper 2, Q1(a) [4 Marks]: Solve (1) $T(n) = T(\sqrt{n}) + 1 \implies \mathbf{O(\log \log n)}$; (2) $T(n) = 3T(n/2) + n \implies \mathbf{O(n^{\log_2 3})}$.
⭐ High Probability Topic 1.2

Decision Tree Lower Bound for Comparison Sorting ($\Omega(n \log n)$)

💡 Asli Baat (1-Sec Recall): Duniya ka koi bhi comparison sort $n$ elements ko $O(n)$ me sort nahi kar sakta. Kyunki $n!$ possible permutations hoti hain, aur unhe pehchan-ne ke liye binary decision tree ki height kam se kam $\log_2(n!) = \mathbf{\Omega(n \log n)}$ honi hi padegi!
📐 Core Mathematical Proof:
Tree with height $h$ has at most $2^h$ leaves. To distinguish all $n!$ permutations, $2^h \ge n! \implies h \ge \log_2(n!) \ge \sum_{i=n/2}^n \log_2(n/2) = \frac{n}{2}\log_2(n/2) = \mathbf{\Omega(n \log n)}$.
📚 CLRS 3rd Ed. & Exam Questions:
  • CLRS Ch. 8, Section 8.1 (Theorem 8.1): Draw decision tree for sorting 3 elements $\langle a_1, a_2, a_3 \rangle$ with 6 leaves.

🔥 Guaranteed Question Topic 2.1

Median of $k$ Sorted Arrays (Total Size $n$)

💡 Asli Baat (1-Sec Recall): $k$ alag-alag sorted arrays ka overall median nikaalna hai. Har array ke pehle element ko utha kar size-$k$ ke Min-Heap me daal do. Har step pe smallest element bahar nikalo aur usi array ka agla element heap me dalo. $\lfloor n/2 \rfloor$ baar karne par exact median mil jata hai in $\mathbf{O(n \log k)}$!
📐 Complexity & Data Structure:
Time: $O(k + n \log k) = \mathbf{O(n \log k)}$ | Auxiliary Space: $\mathbf{O(k)}$ (min-heap storing only $k$ pointers).
Exam Scenario / Disguise Underlying Paradigm Declared State / Data Structure 4-Section Answer Rubric
Aggregating telemetry / finding median from $k$ sorted log streams Tournament Min-Heap Selection Heap $H$ of tuples $(val, arr\_id, idx)$ of size $k$ 1. State Min-Heap of size $k$
2. Insert $A_i[0]$ for all $i \in [1..k]$
3. Loop $n/2$ times: `(val, i, j) = ExtractMin(H)`; insert $(A_i[j+1], i, j+1)$
4. Time: $O(n \log k)$, Space: $O(k)$

⭐ High Probability Topic 2.2

Fast Modular Exponentiation ($a^b \bmod n$) & Josephus Invariant

💡 Asli Baat (1-Sec Recall): $a^b \bmod n$ ko $O(\log b)$ me nikaalne ke liye power $b$ ko har step pe aadha karte jao. Josephus game me agar $n = 2^m + l$ log hain, toh jeetne wala hamesha **$2l + 1$** hota hai (binary number ka pehla bit utha kar end me laga do)!
📐 Core Formulas:
• $3^{83} \bmod 17$: Fermat Little Theorem $\implies 3^{16} \equiv 1 \pmod{17} \implies 83 = 16(5) + 3 \implies 3^3 = 27 \equiv \mathbf{10} \pmod{17}$.
• Josephus for $n = 2^m + 1 \implies W = 2(1) + 1 = \mathbf{3}$. For $n = 2^m - 1 = 2^{m-1} + (2^{m-1}-1) \implies \mathbf{2^m - 3}$.
📚 CLRS 3rd Ed. & Exam Questions:

🔥 Guaranteed Question Topic 3.1

Matrix Chain Parenthesizations & Catalan Series ($f(7)=132, f(8)=429$)

💡 Asli Baat (1-Sec Recall): $n$ matrices ko parenthesize karne ke kitne alag raaste hain? Yeh hamesha **Catalan Number** $C_{n-1}$ hota hai! Recurrence hota hai $f(n) = \sum f(k)f(n-k)$. Value yaad rakho: $f(7) = C_6 = \mathbf{132}$, aur $f(8) = C_7 = \mathbf{429}$. Aur yeh exponential $\mathbf{\Omega(2^n)}$ hota hai!
📐 Recurrence & Catalan Values:
• $f(n) = \sum_{k=1}^{n-1} f(k) f(n-k)$ with $f(1) = 1 \implies f(n) = C_{n-1} = \frac{1}{n}\binom{2n-2}{n-1}$.
• Series: $C_0=1, C_1=1, C_2=2, C_3=5, C_4=14, C_5=42, \mathbf{C_6=132}, \mathbf{C_7=429}$.
• Proof of $\Omega(2^n)$: $f(n) \ge 2 f(n-1) \ge 2^{n-2} \implies \mathbf{f(n) = \Omega(2^n)}$.
📚 CLRS 3rd Ed. & Exam Questions:
  • CLRS Ch. 15, Section 15.2 (Theorem 15.1): Counting parenthesizations recurrence $P(n) = \Omega(2^n)$.
  • Actual Paper 2, Q1(b) [6 Marks]: Recurrence for $f(n)$, find $f(7)=132$ and $f(8)=429$, and prove $f(n) = \Omega(2^n)$.
🔥 Guaranteed Question Topic 3.2

Probability of Exactly $k$ Heads from $n$ Biased Coins ($p_1 \dots p_n$)

💡 Asli Baat (1-Sec Recall): $n$ biased coins hain jinka heads aane ka chance $p_i$ hai. Exactly $k$ heads aane ka DP recurrence hota hai: $DP[i][j] = DP[i-1][j-1] \cdot p_i + DP[i-1][j] \cdot (1 - p_i)$. Base case: $DP[0][0] = 1.0$. Time complexity $\mathbf{O(n \cdot k)}$ aur space $\mathbf{O(k)}$!
📐 Recurrence & Complexity:
$DP[i][j] = DP[i-1][j-1] \cdot p_i + DP[i-1][j] \cdot (1 - p_i)$ with $DP[0][0]=1$, $DP[0][j]=0$ ($j>0$).
Time: $\mathbf{O(n \cdot k)}$ | Space: $\mathbf{O(k)}$ (rolling array).
Exam Scenario / Disguise Underlying Paradigm Declared State 4-Section Answer Rubric
$n$ independent server components with survival probabilities $p_i$, calculate chance exactly $k$ survive Forward Probability DP $DP[i][j]$ = prob of $j$ heads in first $i$ coins 1. State Probability DP
2. Recurrence: $DP[i][j] = DP[i-1][j-1] p_i + DP[i-1][j](1-p_i)$
3. Pseudocode: 2 nested loops, $i \in [1..n], j \in [0..k]$
4. Time: $O(nk)$, Space: $O(k)$

⭐ High Probability Topic 3.3

Longest Arithmetic Progression Subsequence (LAPS)

💡 Asli Baat (1-Sec Recall): Array me sabse lamba Arithmetic Progression dhoondhna. Pehle array sort karo, phir 2D table $L[i][j]$ banao. Middle element $A[i]$ par focus karo aur two-pointers $k$ aur $j$ se check karo: agar $A[k] + A[j] == 2A[i]$ hai, toh $L[i][j] = L[k][i] + 1$! Complexity $\mathbf{O(n^2)}$.
📐 Recurrence & Two-Pointer Invariant:
Sorted array $A[1..n]$. $L[i][j]$ = length of AP ending at $A[i], A[j]$.
If $A[k] + A[j] == 2A[i]$: $L[i][j] = L[k][i] + 1$. Time: $\mathbf{O(n^2)}$, Space: $\mathbf{O(n^2)}$.

Backtracking Strategy & 4-Queens State-Space Tree

💡 Asli Baat (1-Sec Recall): Backtracking depth-first search hota hai with pruning. $X[1..4]$ vector me $X[k]$ column number hai. Bounding condition: $X[k] \ne X[i]$ (same column nahi) aur $|X[k] - X[i]| \ne |k - i|$ (same diagonal nahi). 4-Queens ke do solutions hote hain: **(2, 4, 1, 3)** aur **(3, 1, 4, 2)**!
📐 Bounding Condition & Solutions:
$\text{Place}(k, i) \iff \forall j < k: X[j] \ne i \land |X[j] - i| \ne |j - k|$. Solutions: $(2, 4, 1, 3)$ and $(3, 1, 4, 2)$.

🔥 Guaranteed Question Topic 5.1

Max-Flow Min-Cut Theorem & Edmonds-Karp ($O(V E^2)$)

💡 Asli Baat (1-Sec Recall): Graph me $s$ aur $t$ ke beech bhej sake wala maximum flow hamesha sabse sasti diwaar (cut) ki capacity ke barabar hota hai! Edmonds-Karp infinite loop se bachne ke liye BFS se shortest path dhoondhta hai. Complexity hoti hai $\mathbf{O(V E^2)}$ kyunki har edge maximum $V/2$ times critical banti hai.
📐 Axioms & Theorem Equivalence:
• Capacity Constraint: $0 \le f(u, v) \le c(u, v)$. Flow Conservation: $\sum f(u, v) = 0$ ($u \ne s, t$).
• Min-Cut Partition: $S = \{v \in V \mid \text{path from } s \text{ to } v \text{ in } G_f\}$, $T = V \setminus S$. Then $|f| = c(S, T)$.

Unit VI: Theory of NP, Approximation & Randomized Algorithms

Prover-Verifier NP, 3-SAT to CLIQUE, Monte Carlo vs Las Vegas, and Planar Bisections

🔥 Guaranteed Question Topic 6.1

Randomized Algorithms: Monte Carlo vs Las Vegas (Popular Element $\ge n/3$)

💡 Asli Baat (1-Sec Recall): **Monte Carlo**: Time fix rehta hai ($O(n)$) par answer me chhota sa error chance hota hai. Agar error $\le 3^{-100}$ chahiye, toh $m = 271$ random samples uthao. **Las Vegas**: Answer hamesha 100% sahi hota hai par time random hota hai. Random candidate uthao aur verify karo; average sirf 3 attempts lagenge ($E[T] \le 3$)!
📐 Mathematical Calculations:
• Monte Carlo: $P(\text{fail in } m) \le (1 - 1/3)^m = (2/3)^m \le 3^{-100} \implies m \ge \frac{100 \ln 3}{\ln(1.5)} \approx \mathbf{271\text{ trials}}$.
• Las Vegas: Geometric distribution with $p \ge 1/3 \implies E[\text{trials}] = 1/p \le 3 \implies \mathbf{E[T] = \Theta(n)}$. Zero error probability.
Algorithm Type Time Complexity Correctness Guarantee Exact Mechanism for $\ge n/3$
Monte Carlo Deterministic $O(n)$ Bounded Error ($\le 3^{-100}$) Sample $m=271$ random elements, count frequencies linearly, return max
Las Vegas Expected $\Theta(n)$ 100% Deterministically Correct Pick random index $i$, verify count in $O(n)$. If $\ge n/3$ return; else retry.

  • Actual Paper 2, Q5 [8 Marks]: Full question on Monte Carlo ($3^{-100}$) vs Las Vegas expected time.
⭐ High Probability Topic 6.2

Prover-Verifier Definition of NP & 3-SAT to CLIQUE Reduction

💡 Asli Baat (1-Sec Recall): **NP** ka matlab: agar koi solution (certificate $w$) de de, toh verifier algorithm $V(x, w)$ polynomial time me check kar lega ki solution sahi hai. 3-SAT se CLIQUE banana bohot simple hai: har clause ke 3 literals ke 3 nodes banao, aur non-contradictory nodes ke beech edge banao. 3-SAT satisfiable tabhi hoga jab graph me $k$ size ka CLIQUE milega!
📐 Reduction Gadget:
Formula $\phi$ with $k$ clauses. Create 3 vertices per clause. Edge between $u$ in clause $r$ and $v$ in clause $s$ ($r \ne s$) iff literals are non-negations ($l_u \ne \neg l_v$). $\phi \in \text{3-SAT} \iff G$ has clique of size $k$.
