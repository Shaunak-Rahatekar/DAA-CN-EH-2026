Topic 1.1: Square Root Recurrence & Master Theorem

[-]
💡 Asli Baat (1-Sec Intuition): Recurrence me agar √(n) dikhe toh panic mat karo! Domain variable n = 2m substitute karo, jisse recurrence normal binary search S(m) = S(m/2) + 1 ban jata hai. Answer seedha O(log log n) aayega!
🎯 Formal Academic Definition: Domain substitution transforms non-polynomial subproblem reductions into linear form. By setting n = 2m (hence m = log₂ n), T(n) = T(√n) + 1 becomes S(m) = S(m/2) + 1 = Θ(log m) = Θ(log log n).
📐 Crystal-Clear Formulas (No Raw Syntax):
• Square Root Recurrence: T(n) = T(√(n)) + 1  ⟹  Substitute n = 2m  ⟹  S(m) = S(m/2) + 1  ⟹  T(n) = O(log log n)
• Master Theorem Case 1: T(n) = 3T(n/2) + n  ⟹  Watershed nlog₂ 3 ≈ n1.585  ⟹  Since n1 = O(n1.585 - 0.585), T(n) = Θ(nlog₂ 3) ≈ O(n1.585)

Topic 1.2: Decision Tree Lower Bound for Sorting (Ω(n log n))

[-]
💡 Asli Baat: Koi bhi comparison sort n elements ko O(n) me sort nahi kar sakta kyunki n! possible orders ko distinguish karne ke liye binary tree ki height kam se kam Ω(n log n) honi hi padegi!
📐 Stirling's Lower Bound Derivation: Tree height h has at most 2h leaves. To distinguish all n! permutations: 2h ≥ n!  ⟹  h ≥ log₂(n!) = ∑i=1n log₂ i ≥ (n/2) log₂(n/2) = Ω(n log n).
📚 CLRS Mapping: CLRS Ch. 8, Section 8.1 (Theorem 8.1). Draw tree for n=3 with 6 leaves.

Topic 3.2: Poisson Binomial Coins DP (Probability of Exactly k Heads)

[-]
💡 Asli Baat: n biased coins me se exactly k heads chahiye. DP table banao: i-th coin ya toh heads aayega (pi chance se, prior j-1 heads) ya tails aayega ((1-pi) chance se, prior j heads)!
📐 Recurrence & Complexity:
DP[i, j] = DP[i-1, j-1] · pi + DP[i-1, j] · (1 - pi)
Base Cases: DP[0, 0] = 1.0, DP[0, j] = 0.0 (for j > 0).
Time Complexity: O(n · k)  |  Space Complexity: O(k) (rolling 1D array).
📚 Exam Question: Actual Paper 2, Q3(b)(ii) [7 Marks] — Pseudocode, correctness argument, and complexity.
⭐ High Probability

Topic 3.3: Longest Arithmetic Progression Subsequence (LAPS)

[-]
💡 Asli Baat: Array sort karke 2D DP L[i, j] banao. Middle element A[i] fix karo: agar A[k] + A[j] == 2A[i], toh L[i, j] = L[k, i] + 1! Time complexity O(n²).
📐 Recurrence & Two-Pointer Invariant:
L[i, j] = length of AP ending at A[i], A[j] in sorted array A.
If A[k] + A[j] == 2A[i]: L[i, j] = L[k, i] + 1  |  Time: O(n²)  |  Space: O(n²)

Topic 6.1: Randomized Algorithms: Monte Carlo vs Las Vegas (Popular Element ≥ n/3)

[-]
💡 Asli Baat: **Monte Carlo**: Time fix rehta hai (deterministic O(n)) par chhota sa error chance hota hai (error ≤ 3⁻¹⁰⁰ ke liye m = 271 samples uthao). **Las Vegas**: Answer 100% sahi hota hai par time random hota hai (average sirf 3 trials lagenge, E[T] = Θ(n))!
📐 Mathematical Derivations:
• Monte Carlo: P(fail) ≤ (1 - 1/3)m = (2/3)m ≤ 3⁻¹⁰⁰  ⟹  m ≥ 100 ln(3) / ln(1.5) ≈ 271 trials.
• Las Vegas: Geometric distribution with p ≥ 1/3  ⟹  E[trials] = 1/p ≤ 3  ⟹  E[Time] = Θ(n). Zero error.
📚 Exam Question: Actual Paper 2, Q5 [8 Marks] — Complete question on Monte Carlo vs Las Vegas for popular element.

Topic 6.2: Prover-Verifier Definition of NP & 3-SAT to CLIQUE

[-]
💡 Asli Baat: **NP** ka matlab hai: agar koi candidate certificate w de de, toh verifier algorithm polynomial time me check kar lega ki solution valid hai. 3-SAT se CLIQUE reduction me har clause ke 3 literals ke 3 nodes banao; non-contradictory nodes ko jodo. Formula satisfiable ⟺ graph me k size ka CLIQUE milega!
📐 Reduction Construction: Create 3 vertices per clause. Edge between u and v iff they belong to different clauses and literals are non-contradictory (lu ≠ ¬lv).
Formula φ ∈ 3-SAT  ⟺  G has a clique of size k.
